# Auto Dimension Algorithm Core V2

## 目标

V2 保留 Vectorworks 2025/2026 的工具模式、原生尺寸创建、工作平面与 Undo/Redo 事务，新增一个不依赖 Vectorworks SDK 的算法层：

- `include/vwad/AutoDimensionAlgorithms.h`
- `tests/AutoDimensionAlgorithmsTests.cpp`

宿主源码负责提取和写回，算法层负责数值判断、几何分析、候选选择与布局。这样可以在没有 Vectorworks 进程和受许可 SDK 的环境中执行确定性回归测试。

## 已接入算法

### 尺度感知容差

线性容差采用：

```text
epsilon = max(absolute, relative * max(1, geometryScale))
```

方向平行判断使用无量纲角度容差，避免把带长度平方单位的叉积与线性距离直接比较。

### 主方向和旋转包围盒

主方向使用四角度圆统计：

```text
C = sum(length_i * cos(4 * theta_i))
S = sum(length_i * sin(4 * theta_i))
theta = atan2(S, C) / 4
confidence = hypot(C, S) / sum(length_i)
```

`4 * theta` 使互相垂直的边支持同一个局部坐标框架，不再受固定 5° 分箱边界影响。封闭对象只有在置信度不低于 `0.20` 且偏离水平/垂直超过 `2°` 时才生成局部轴尺寸。

点集先求凸包，再遍历凸包边方向计算最小面积旋转包围盒。尺寸方向由最终包围盒端点计算，避免轴互换后方向符号不一致。

### 路径拓扑和尺寸车道

连续标注不再按 `minX` 排序。算法使用空间哈希合并容差内端点，将线段构造成图，再提取连续链：

- 开放链从度为 1 的顶点开始；
- 闭合链从任意未使用边开始；
- 分支处优先选择转角最小的下一条边；
- 不连通路径分别形成尺寸链。

同一链使用统一偏移。多个投影区间重叠的链通过区间图着色分配不同尺寸车道。交互式快速链和任意角度链也在第一段后锁定统一偏移。

### 精确交线

交线模式现在使用共享的稳健线段求交。顶层圆、椭圆和圆弧使用解析二次方程求交，再按圆弧参数角检查 sweep 范围，不再使用包围盒四边代替曲线。

交点用空间哈希进行相对容差去重，平均复杂度由线性扫描的 `O(H²)` 降为 `O(H)`。嵌套在符号/组内且带复杂非均匀变换的曲线仍使用遍历线段回退。

### 代表尺寸选择

开放路径不再简单选择最长三条边。算法把端点和方向族视为需要覆盖的特征，以长度倒数作为候选代价，使用加权集合覆盖选择最多三条代表边，然后删除冗余候选。

### 中心标注

中心点仍生成恰好 `N-1` 条尺寸，但边权不再只有欧氏距离。算法先从中心点协方差估计局部轴，对偏离局部水平/垂直的边加入惩罚，再求生成树。规则网格中会优先连接同行、同列对象，孤立对象仍能保持整体连通。

### 文字布局

文字避让分为两阶段：

1. 无 SDK 的离散全局布局为每个文字枚举沿尺寸轴和法向的候选位置，最小化重叠面积与移动距离；使用冲突优先贪心初始化和三轮确定性局部改进。
2. 将选中候选写回 Vectorworks 后，保留原有的实测对象边界迭代作为宿主精修和外推回退。

这个组合减少了原算法按选择顺序逐个移动产生的顺序依赖，同时不假设 SDK 的最终文字排版尺寸。

## 复杂度

| 算法 | 复杂度 |
| --- | --- |
| 空间点去重 | 平均 `O(N)` |
| 主方向统计 | `O(E)` |
| 凸包 | `O(P log P)` |
| 最小面积包围盒 | 当前上限内 `O(H²)` |
| 路径链提取 | 平均 `O(V + E)` |
| 解析椭圆求交 | 每个对象 `O(1)` |
| 正交偏好生成树 | `O(N²)` |
| 区间车道分配 | `O(N log N)` |
| 文字离散布局 | `O(K * D²)`，`K` 为每个文字的有限候选数 |

Vectorworks 几何采集仍保留 8 层、512 对象、512 点和 256 线段的安全上限。

## 自动测试

```powershell
cmake -S . -B build/algo-test -G Ninja -DCMAKE_BUILD_TYPE=Release -DCMAKE_CXX_COMPILER=g++
cmake --build build/algo-test
ctest --test-dir build/algo-test --output-on-failure
python tools/test_autodim_geometry.py
```

覆盖内容包括：

- 小尺度与大尺度容差；
- 带噪声旋转矩形的连续主方向；
- 凸包旋转包围盒；
- 空间哈希跨网格点合并；
- 打乱输入顺序的路径拓扑恢复；
- 稳健线段求交；
- 椭圆、整圆和半圆弧求交；
- 区间车道；
- 正交偏好中心生成树；
- 多文字与源障碍全局布局；
- 加权集合覆盖和代表边选择；
- 大坐标下的旋转、平移、缩放不变性。

## Vectorworks 实机回归重点

1. 旋转矩形、旋转符号、正方形和 L 形对象的局部宽高方向。
2. 开放回折多段线、竖向路径、闭合路径和多条不连通路径的连续标注顺序及车道。
3. 交线穿过圆、椭圆、半圆、优弧和端点相切时的交点数量。
4. 规则灯具网格与不规则散点对象的中心连接方向。
5. 单尺寸加源对象、多尺寸密集堆叠和文字已在尺寸线外的避让写回。
6. 快速链后续短段/长段混合时，尺寸线偏移保持统一。

解析曲线的角度方向、对象实体矩阵和 Vectorworks 最终文字包围盒仍属于宿主行为，必须在 2025/2026 各执行一次上述冒烟测试。
