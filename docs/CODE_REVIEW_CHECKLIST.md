# 代码审查速查清单（评审人贴 PR 用）

优先级：🔴 P0 必须修（阻塞合并） / 🟡 P1 应该修 / 💭 P2 建议。
每条评论格式：`🔴 类别：标题  file:line —— 为什么 —— 建议改法`。

## 正确性
- 🔴 未初始化 / 空指针 / 越界 / 除零？边界（空集合、退化输入、零长向量）挡了？
- 🔴 悄悄改变既有行为？（偏移符号、坐标基准、undo 配对、默认参数）
- 🔴 SDK/第三方调用返回值语义与代码假设一致？（`GetEndPoints`=void 非 bool；`GetObjectVariable` 失败返 false）
- 🟡 浮点比较用容差？阈值是否绝对→相对更稳？
- 🟡 循环/递归死循环、整数溢出、符号翻转？

## 安全
- 🔴 外部输入/文件/网络校验？路径防穿越？
- 🔴 注入面（SQL/命令/模板/序列化）走参数化/白名单？
- 🟡 密钥/token 误入源码或日志？

## 可维护性
- 🟡 命名自解释？魔法数提常量？
- 🟡 可单测纯逻辑是否从巨型函数抽离？
- 🟡 两份须一致的源（2025/2026）有无一致性测试兜底？
- 💭 注释讲"为什么"？复杂几何/算法有推导出处？

## 性能
- 🟡 N+1 / 重复遍历 / 每帧分配？大数据集（>170 灯具、长音频）退化？
- 💭 不必要值拷贝，可 const ref？

## 测试
- 🔴 修复类 PR 带复现/回归测试？纯函数改动有单测？
- 🟡 边界与异常路径覆盖（垂直转角偏移符号、反转点、撤销失败回滚）？
- 🟡 新增"通用"数学补了项目专属语义用例？

## 专项
- C++/Qt/VW：内存所有权配对、`WorldCoord`=double、预编译头顺序、跨平台宏。
- VW 专属：双版本字节一致；撤销原子性（任何"新建换旧"失败须 `UndoAndRemove` 回滚）；trace 文件名带版本戳且被规范化。
- TS/React：Convex action↔前端 wizard 类型契约；WIP 多时先审状态再动。
- Flutter：PU 对齐全量 `FullSizePlusWorker`；纯时间模型禁 BPM/beat。
- Lua/Py：全局副作用、路径硬编码、venv 隔离。

## 合并门槛（DoD）
1. 🔴 全部 P0 已解决；2. §3 CI 全绿（含双版本）；3. ≥1 Reviewer 批准且评论清零；4. PR 模板+自审清单已填；5. 无"改坏现有行为"风险。
