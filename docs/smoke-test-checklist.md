## 1. offset 侧边约定（确认引擎侧边解析）

**目的**：确认 `CreateLinearDimension` 的 `startOffset` 正负号对应世界坐标哪一侧，防止尺寸线落到错误一侧。

**前置**：新建空文档，顶视图，毫米。

**步骤**：
1. 选一条水平线段 → 使用「线对象标注」→ 观察尺寸线落在线段上方还是下方。
2. 用「边界标注」选中两个矩形 → 观察宽度尺寸（下方）与高度尺寸（右侧）。
3. 用「符号定位」点一个符号 → 观察横向/纵向尺寸落位。
4. 用「快速连续标注」连续点三个点 → 观察水平段/垂直段尺寸线方向。

**预期**：各模式的尺寸线都落在图形外侧（不压在图形上）。若某模式尺寸线压在图形上或方向相反，记录该模式并在代码中翻转该处 offset 符号。

## 3. 链合并不叠加（P2-6：`CreateChainDimension` 是否消费输入尺寸）

**目的**：确认「合并标注」不会在原尺寸之上叠加出重复对象。

**前置**：顶视图；画一条水平线，先手动/自动生成 2~3 段相邻对齐尺寸。

**步骤**：
1. 选中全部 2~3 段尺寸 → 切换「合并标注」编辑模式 → 点一下完成。
2. 观察：是否只剩一个链尺寸对象？原尺寸是否消失？
3. **立即撤销**（一次）→ 观察：原尺寸是否全部恢复？是否多出一个链对象（叠加）？
4. 再选 3 段及以上重复一次合并 + 撤销，确认中间链不残留。

**预期**：
- 合并后只有一个链对象，原尺寸消失；
- 撤销后原尺寸恢复，且**不出现**多余的中间链/半成品链（本清单对应评审修复：中间链不注册 undo）。

## 5. 转换 offset 折算位置对照（§3.2 W2）

**目的**：确认「转换标注」按 `offset/cosθ` 折算后，转换前后尺寸线位置不「跳位」。

**前置**：画一条约 30° 的斜线段。

**步骤**：
1. 用「线对象标注」生成斜线的对齐尺寸，记下尺寸线到测量轴的**视觉距离**。
2. 选中该尺寸 → 「转换标注」→ 完成。
3. 对比转换前后尺寸线的**世界位置**（应在视觉上基本不移动；水平投影后尺寸线高度 = 原法向距离 ÷ cosθ）。

**预期**：尺寸线位置无肉眼可见跳位；若仍明显移动，记录方向（偏近/偏远）以便修正公式或符号。

## 7. 任意角度链（新功能）

**前置**：顶视图；先画一条约 45° 的参考线便于对齐点击。

**步骤**：
1. 切到「任意角度链」→ 点起点 A → 弹「已锚定起点，点击下一点确定链方向」。
2. 点第二点 B（与 A 拉开距离）→ 生成第一段尺寸 A→B，方向沿 AB。
3. 沿参考线继续点 C、D → 每段尺寸沿 AB 方向**共线**续接（前一点的投影与当前点投影之间）。
4. 点一个明显偏离 AB 的点 → 尺寸仍投影到 AB 轴上，读数=沿轴投影距离。
5. 按 ESC → 弹「任意角度链已结束」；撤销逐段回退。
6. 验证 offset 侧边：尺寸线应统一落在参考线同一侧，不压图形。

**预期**：两点定方向、后续沿 θ 轴共线续接、偏离点正确投影、ESC 结束。**若尺寸线落在错误一侧，把 `AutoDimensionObj.cpp` 任意角度链分支的 `-offset` 改 `+offset`（2025/2026 同步）后重测。**

## 10. 设置面板

**目的**：验证 W5 设置面板的默认值、持久化、实时生效、校验与兜底。

**前置**：顶视图。

**步骤**：
1. **默认值回归**：打开「设置」（模式栏齿轮）→ 不改值点确定 → 各模式输出与未改设置前一致。
2. **实时生效**：工具激活状态下把「尺寸偏移基数」改为 50 → 确定 → 立即用连续标注 → 尺寸线明显外移（无需重启工具）。
3. **持久化**：偏移基数改为 50 → 确定 → **重启 Vectorworks** → 打开设置 → 值仍为 50。
4. **范围校验/兜底**：迭代上限输入 0 → 确定 → 确认被钳制到 ≥1；手工把 Saved Settings 键删掉（或在设置中填非法文本）→ 行为回退默认且不崩。
5. **按钮**：齿轮按钮出现、点击弹窗、帮助文字为中文；切换 10+11 个模式按钮不受影响。
